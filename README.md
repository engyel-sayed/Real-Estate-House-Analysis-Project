# 🏘️ Real-Estate-House-Analysis-Project

## 📌 Overview
This Jupyter Notebook contains a comprehensive Exploratory Data Analysis (EDA) and Data Cleaning workflow on the Houses in London dataset sourced from Kaggle. The analysis explores real estate data across London, covering various property features, pricing dynamics, structural attributes, and room counts.
